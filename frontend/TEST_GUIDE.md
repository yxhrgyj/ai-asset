## 常见问题

### Q1: 创建时上传附件，但创建失败怎么办？
A: 附件上传是在资产创建成功后进行的。如果创建失败，不会上传附件，不会产生垃圾数据。

### Q2: 下载全部时，浏览器提示"阻止多个下载"？
A: 在浏览器弹出提示时，选择"允许"即可。每次下载间隔 300ms，减少被拦截的可能性。

### Q3: 为什么第二步和第三步都是可选的？
A: 因为有些用户希望先创建资产框架，稍后再填充内容。灵活的流程适应不同的工作习惯。

### Q4: 下拉框箭头在暗色模式下看不清楚？
A: 当前箭头颜色为 #666，如果切换到暗色主题，可能需要调整颜色。可以在 CSS 中使用 `currentColor` 或主题变量。

## 技术细节

### 创建流程实现
```typescript
// 1. 创建资产基本信息
const created = await assetApi.create(data)

// 2. 如果有内容，保存草稿
if (formData.value.body) {
  await assetApi.saveDraft(created.id, {
    body: formData.value.body,
    changelog: formData.value.changelog
  })
}

// 3. 如果有附件，逐个上传
for (const item of createFiles.value) {
  await assetApi.uploadFile(created.id, item.file, item.relativePath)
}
```

### 批量下载实现
```typescript
for (const file of detail.value.files) {
  const link = document.createElement('a')
  link.href = getDownloadUrl(file)
  link.download = file.relativePath
  document.body.appendChild(link)
  link.click()
  document.body.removeChild(link)
  
  // 延迟避免浏览器拦截
  await new Promise(resolve => setTimeout(resolve, 300))
}
```
